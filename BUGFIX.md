# Баг с инпутом количества. Можно стереть значение и вписать что угодно
Никакие ограничения по коду не стоят. Формальные от 1 до 10 и всё
Что сделал:
- Валидацию через watch 

```
watch(quantity, (newVal: number) => {
  if (newVal > 10) {
    quantity.value = 10
  } else if (newVal < 1) {
    quantity.value = 1
  }
})
```

такое решение частично ломает редактирование, но по времени 25 минут не укладываюсь если переделывать. Как сделать в идеале: в функции добавления сделать проверки на границы и на isInteger и делать existing.quantity += itemQuantity (именно то значение, которое проверяем)
